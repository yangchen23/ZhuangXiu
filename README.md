## 🏠 产品定位

**筑家记** = 装修全周期智能管家 = 记录 + 引导 + 知识 + 灵感

核心设计原则：
- 知识库优先于AI问答（节省token）
- 80% 问题查知识库解决，20% 个性化场景才用AI
- 开工前/开工后双模式
- 首页 = Dashboard 总览（风格 + 知识库 + 花费 + 准备进度 + 推荐）
- 天气影响装修决策（雨天不去建材市场）

## 📱 微信小程序（V4.5 实现进度）

> 基于 index.html 交互原型，用**原生微信小程序**实现完整 UI 与核心交互。

### 如何运行

1. 打开微信开发者工具 → 导入项目 → 选择本目录 `D:\Project\ZhuangXiu`
2. AppID 使用测试号（`touristappid`）或个人 AppID 均可
3. 编译后即可预览：4 Tab + FAB 4宫格 + 预算联动 + 记录筛选

### 已实现

- 自定义 TabBar：首页/参考/日记/我的 + 中央 FAB 4宫格（随手记/拍照/问AI/写日记）
- 首页：3 种天气主题切换、开工准备进度（点击勾选）、预算入口联动
- 参考：灵感（外部收藏 + AI分析、风格速测入口、8 风格图库）+ 知识（分类 + FAQ 展开）
- 日记：总览（阶段流程/今日任务/验收清单可勾选/资料2x2）、计划（当月日历 + 事件）、记录（搜索/标签/按空间3列筛选/自定义添加空间）
- 预算：三卡 + 4 类目分配（90% 超支变红）+ 流水；随手记保存自动入账
- 随手记：文字（本地正则识别金额/品类/空间）+ 语音（模拟）+ 拍照（wx.chooseImage）+ 可改分类/金额/空间
- 写日记：空间/施工类型选择、多图上传、标签，保存进记录
- 问AI：本地关键词模拟回答 + 拍照识别占位
- 风格速测：5 题 → 主风格/辅助/避坑结果
- 拍照留档：拍照/相册、预览、删除（本地存储）
- 风格图库：8 大风格详情（色卡/关键词/案例）+ 收藏
- 知识文章：14 篇装修干货（瓷砖/地板/涂料/卫浴/水电避坑/攻略等）
- 预算估算：城市/面积/风格/档次 → 总价区间 + 四类分配，可设为总预算
- 施工方推荐 / 工人详情：示例数据 + 联系占位
- 空间管理：增删自定义空间，点击跳转日记按空间筛选
- 家庭成员 / 验收清单（7 阶段勾选）/ 家电选购指南 / 设置（重置数据）

### 数据说明

- 当前为**本地模拟模式**：所有数据存 `wx.setStorageSync`（预算/记录/空间/收藏/任务/照片）
- 接入云端：在 `miniprogram/config.js` 填入 `CLOUD_ENV` 云环境 ID 即可开启云开发，
  后续把 `utils/store.js` 的读写换成云数据库调用即可（数据结构已按集合划分）

### AI 接入（DeepSeek）

已接入 DeepSeek 的能力：

- **问AI**：对话问答（带装修顾问系统提示词 + 上下文记忆）
- **随手记 → 智能识别归类**：AI 提取金额/品类/空间/规格（失败自动回退本地正则）
- **参考 → 收藏外部内容 → AI 分析提取**：AI 提炼标题/要点数/建议

模型默认 `deepseek-v4-flash`，接口返回模型不存在时自动兜底 `deepseek-chat`（均在 `miniprogram/config.js` 的 `DEEPSEEK` 配置里可改）。

密钥配置（二选一）：

1. **开发调试（推荐先用这个）**：创建 `miniprogram/config.local.js`（已被 .gitignore 忽略，不会提交）：
   ```js
   module.exports = { DEEPSEEK_API_KEY: 'sk-xxx' };
   ```
2. **生产（推荐）**：部署 `cloudfunctions/aiChat` 云函数，在云函数环境变量里配置 `DEEPSEEK_API_KEY`；
   同时把 `miniprogram/config.js` 填上 `CLOUD_ENV`，客户端会自动优先走云函数（密钥不出现在小程序包里）。

注意：直连模式需要在微信公众平台把 `api.deepseek.com` 加入 request 合法域名（开发工具已关闭域名校验可直接调试）；
直连会把密钥打包进小程序，仅限自用调试，正式发布务必改用云函数。

### 真实天气

- 首页天气已接入真实数据：`wx.getLocation` 定位 → Open-Meteo 实时天气 + 空气质量（免费、无需 key）
- 天气主题（晴/雨/多云）随真实天气自动切换；右上角「🔄 刷新」可手动更新（10 分钟缓存）
- 定位被拒绝/失败时自动回退到 `config.js` 中 `WEATHER.DEFAULT_LOCATION`（默认深圳）
- 定位后**自动显示所在城市**（内置全国 300+ 主要城市坐标表就近匹配，免 key、离线可用）
- 想要显示街道级地址：到 [腾讯位置服务](https://lbs.qq.com) 注册小程序 key（勾选 WebServiceAPI），
  把 key 填进本地 `miniprogram/config.local.js` 的 `TENCENT_MAP_KEY`（已被 gitignore，不会公开），
  会自动升级为「城市 · 区 街道」格式
- 生产环境需在公众平台把 `api.open-meteo.com`、`air-quality-api.open-meteo.com` 加入 request 合法域名
  （如配置了腾讯 key，还需加入 `apis.map.qq.com`）
