## 🏠 产品定位

**筑家记** = 装修全周期智能管家 = 记录 + 引导 + 知识 + 灵感

核心设计原则：
- 知识库优先于AI问答（节省token）
- 80% 问题查知识库解决，20% 个性化场景才用AI
- 开工前/开工后双模式
- 首页 = Dashboard 总览（风格 + 知识库 + 花费 + 准备进度 + 推荐）
- 天气影响装修决策（雨天不去建材市场）

## 📱 微信小程序（V4.5 实现进度）

> 基于 index.html 交互原型，用**原生微信小程序**实现完整 UI 与核心交互。

### 如何运行

1. 打开微信开发者工具 → 导入项目 → 选择本目录 `D:\Project\ZhuangXiu`
2. AppID 使用测试号（`touristappid`）或个人 AppID 均可
3. 编译后即可预览：4 Tab + FAB 4宫格 + 预算联动 + 记录筛选

### 已实现

- 自定义 TabBar：首页/参考/日记/我的 + 中央 FAB 4宫格（随手记/拍照/问AI/写日记）
- 首页：3 种天气主题切换、开工准备进度（点击勾选）、预算入口联动
- 参考：灵感（外部收藏 + AI分析、风格速测入口、8 风格图库）+ 知识（分类 + FAQ 展开）
- 日记：总览（阶段流程/今日任务/验收清单可勾选/资料2x2）、计划（当月日历 + 事件）、记录（搜索/标签/按空间3列筛选/自定义添加空间）
- 预算：三卡 + 4 类目分配（90% 超支变红）+ 流水；随手记保存自动入账
- 随手记：文字（本地正则识别金额/品类/空间）+ 语音（模拟）+ 拍照（wx.chooseImage）+ 可改分类/金额/空间
- 写日记：空间/施工类型选择、多图上传、标签，保存进记录
- 问AI：本地关键词模拟回答 + 拍照识别占位
- 风格速测：5 题 → 主风格/辅助/避坑结果
- 拍照留档：拍照/相册、预览、删除（本地存储）

### 数据说明

- 当前为**本地模拟模式**：所有数据存 `wx.setStorageSync`（预算/记录/空间/收藏/任务/照片）
- 接入云端：在 `miniprogram/config.js` 填入 `CLOUD_ENV` 云环境 ID 即可开启云开发，
  后续把 `utils/store.js` 的读写换成云数据库调用即可（数据结构已按集合划分）

### 已知演示占位

- AI 对话/风格分析/拍照识别为本地模拟，未接 DeepSeek / 视觉模型
- 风格图库、知识库文章为入口占位（待 Phase 2 填充内容）
- 家庭成员、验收清单详情、设置等子页面为 Toast 占位
