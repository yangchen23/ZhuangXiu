## 🏠 产品定位

**筑家记** = 装修全周期智能管家 = 记录 + 引导 + 知识 + 灵感

核心设计原则：
- 知识库优先于AI问答（节省token）
- 80% 问题查知识库解决，20% 个性化场景才用AI
- 开工前/开工后双模式
- 首页 = Dashboard 总览（风格 + 知识库 + 花费 + 准备进度 + 推荐）
- 天气影响装修决策（雨天不去建材市场）
