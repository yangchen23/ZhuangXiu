# 筑家记 V4 — 装修智能管家 · 升级方案

> 状态：方案设计中 | 解决 3 个用户反馈 | 4 Tab + FAB 4宫格新架构

---

## 用户反馈（3 个核心问题）

1. **AI/拍照埋太深** — V3 知识页底部，每次都要滑到底，违反"快操作应该最易触达"原则
2. **风格还没定** — 用户没开工，V3 的"工序进度+阶段感知"对他用不上，需要"装修前"模式
3. **随手记缺失** — 装修现场要快速记"买了什么花了多少"，需要文字/语音/拍照 + 自动归类

### 1.2 核心功能模块

#### A. 3 分钟风格速测
- 5-8 道二选一题目（"大横厅 vs 温馨小客厅"、"原木色 vs 黑白灰" 等）
- 实时计算风格倾向
- 完成后给出"你的风格画像"：主风格 1 个 + 副风格 2 个 + 避坑风格 1 个
- 一键查看对应风格图库

#### B. 风格图库（8 大类）
- **预置内容**：每个风格 15-25 张图（从公开素材/合作设计师供稿）
- **图片结构化标签**：风格 / 空间类型（客厅/卧室/...）/ 色系 / 关键元素
- **交互**：点击图片进大图浏览，长按收藏，双击点赞
- **瀑布流展示**：缩略图 + 风格名 + 收藏数

#### C. 我的灵感库
- 收藏的所有图（瀑布流）
- 支持按"风格/空间/标签"筛选
- 一键导出为 PDF 给设计师参考
- "AI 帮我分析我的收藏" → 推荐主风格

#### D. AI 风格分析（拍照识别 2.0）
- 用户拍照（家/画册/家具/效果图）
- AI 识别风格倾向（北欧 60% + 日式 30% + 侘寂 10%）
- 推荐相关材料知识（"你喜欢原木色 → 推荐知识：原木风地板选购"）
- 推荐类似图

#### E. 专业方案（升级版）
- **上传户型图** → AI 分析空间 → 推荐布局
- **预算估算器**（按城市/面积/风格/精装档次 → 输出预算范围）
- **设计师对接**入口（接入合作设计师 / 装修公司，收取中介费）
- **开工准备清单**：选施工方/签合同/办手续 一条龙引导

#### F. 外部内容收藏 + AI分析（用户新增反馈）
> 刷小红书/抖音/公众号看到好内容，一键收藏 → AI 提炼 → 转化为你的装修知识

**场景举例**：
- 看到「日式厨房必装这 5 个神器」→ 收藏进来 → AI 提炼：「推拉式调味篮、转角拉篮、下拉式吊柜…」→ 加到材料清单
- 看到「水电改造避坑指南」→ 复制链接 → AI 提取 7 个关键注意事项 → 生成 Checklist
- 看到效果图 → 截图收藏 → AI 分析风格/配色/家具 → 推荐搭配方案

**3 种收藏方式**：

| 方式 | 操作 | AI 做了什么 |
|------|------|-----------|
| **🔗 复制链接** | 小红书/抖音/公众号 → 复制链接 → 打开小程序粘贴 | AI 抓取原文 → 提取关键信息 → 结构化总结 |
| **📸 截图/拍照** | 截图 → 打开小程序上传 | OCR 文字识别 + AI 图像分析 → 提取风格/材料/布局要点 |
| **📋 复制文本** | 复制一段文字 → 粘贴 | AI 分析 → 提取知识点/避坑要点/材料清单 |

**AI 分析输出格式**：

```
📄 原标题：日式厨房必装这 5 个神器

📝 AI 提炼要点：
1. 推拉式调味篮 — 充分利用台面下窄柜空间，¥200-500
2. 转角拉篮 — 解决角落取物难问题，¥300-800
3. …

🏷️ 自动标签：#厨房 #收纳 #日式

💡 关联建议：
→ 厨房水电前要预留转角处插座
→ 已加入「材料清单」

⚠️ 避坑提醒：
→ 转角拉篮要看柜体尺寸，别买错规格
```

**内容流转路径**：

```
小红书/抖音/公众号
       ↓  复制链接/截图/复制文本
    筑家记收藏夹
       ↓  AI 分析提取
  ┌────┼────┬─────────┐
  ↓    ↓    ↓         ↓
知识库  材料清单  预算  风格灵感
(避坑指南) (推荐采购) (估价) (搭配方案)
```

## 新增 2：随手记（解决反馈 3）

> 装修现场"快速记录一笔花销"，文字/语音/拍照全支持 + 自动归类

### 2.1 入口

`首页 / 知识 / 灵感 / 我的` 任意页面 → 点击中央 FAB → 选「✏️ 随手记」

### 2.2 随手记弹窗设计

```
┌─────────────────────────────┐
│      ✏️ 随手记                │
├─────────────────────────────┤
│  [📝文字] [🎤语音] [📷拍照]   │   Tab 切换输入方式
│                              │
│  📝 文字输入:                │
│  ┌──────────────────────┐   │
│  │ 在居然之家买了瓷砖   │   │
│  │ 800×800通体，68元/片 │   │
│  │ × 52片 = 3536元      │   │
│  │                       │   │
│  └──────────────────────┘   │
│                              │
│  🤖 AI 智能识别:             │
│  金额: ¥3,536                │
│  品类: 材料 > 瓷砖            │
│  空间: 客厅                  │
│  ✅ 已自动归类                │
│                              │
│  [修改分类]                  │
│                              │
│  [取消]      [保存到预算]    │
└─────────────────────────────┘
```

### 2.3 3 种输入方式

| 方式 | 实现 | 说明 |
|------|------|------|
| **文字** | 文本框 + 本地正则提取金额 | 简单快速 |
| **语音** | 微信原生 `wx.getRecorderManager` + 云函数 STT | 现场手脏时用 |
| **拍照** | 微信相机/相册 + 拍照识别 + OCR 金额 | 拍小票/物品 |

### 2.4 自动归类逻辑

**AI 解析输入文本/语音/图片，返回结构化数据**：

```javascript
{
  rawText: "在居然之家买了瓷砖 800×800通体 68元/片 ×52片",
  amount: 3536,        // 提取金额
  category: "材料",     // 一级分类
  subCategory: "瓷砖",  // 二级分类
  space: "客厅",        // 关联空间（如能识别）
  brand: null,          // 品牌（如能识别）
  spec: "800×800 通体", // 规格
  note: "居然之家",     // 备注
  confidence: 0.92     // AI 识别置信度
}
```

**AI 调用策略（节省 token）**：
- 80% 简单场景（仅金额 + 品类）用本地正则匹配，**不走 LLM**
- 复杂场景（涉及多品类/不确定分类）才调 LLM
- 用户可手动修改分类，确认后入库

### 2.5 预算/流水页（我的 Tab 下）

- 流水列表（按时间倒序）
- 月度饼图：分类占比
- 趋势折线图：每周/每月支出
- 筛选：按品类/空间/月份
- 导出 Excel
