
**¥0 时这段内容的价值**：
- 让用户**预知**接下来要在哪几个类目花钱
- 每一类目有进度条，已花即填充
- 接近超支时（≥90%）变红预警

#### 段 3：近期流水（实时联动）

```
┌─────────────────────────────────────┐

│                                      │
│  [或: 已花的记录]                    │

│     客厅 · 材料                       │
│  ...                                │
└─────────────────────────────────────┘
```

---

### 随手记 ↔ 预算联动（用户已确认强联动）

**随手记保存一条** → 自动写入预算流水 → 首页"已花费"数字 +1 → 预算页"近期流水"出现一条 → 对应类目（材料/人工/家具/家电）进度条 +1 → 达到 90% 时该类目进度条变红。

**实现机制**：
- 随手记弹窗保存时，同时调用预算流的 `addExpense()` 函数
- 预算页和首页 dash-stat 的 ¥X 数字都从同一个 `totalSpent` state 读
- 类目进度条从 `categorySpent[category]` 读

---

### 预算设置（我的 Tab 下放入口，不在预算页本身）

「我的」→「预算设置」：
- 修改总预算（默认 ¥200,000）
- 自定义每类目比例（默认 40/30/20/10）
- 按空间分配预算（可选：客厅/主卧/厨房/主卫...）

预算设置只在需要调整时进，不污染主预算页。
