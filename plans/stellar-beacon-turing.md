## 新增核心能力

### 1. AI装修顾问（一级Tab，全新）
> 小白的第一求助入口——不懂就问、看不懂就拍

**文字对话**：
- "先装中央空调还是先做水电？"
- "卫生间防水要做多高？"
- "800×800 和 750×1500 的瓷砖怎么选？"
- "我家套内90平，半包大概多少钱？"

**拍照问答**（市场空白，核心差异化）：
- 拍一块瓷砖 → 识别品类/规格/大概价位 + 给出选购建议
- 拍一个插座 → 识别品牌型号 + 告知是否适合当前空间
- 拍施工现场 → 识别当前工序 + 检查工艺是否规范
- 拍家具照片 → 识别风格 + 推荐搭配

**智能追问**：
- 用户问"瓷砖怎么选"，AI不只回答，还会反问"你家是地暖吗？有小孩老人吗？采光怎么样？"来给出个性化建议

### 2. 装修流程引擎（首页升级）
> 不知道先做什么后做什么？跟着流程走就行

**内置标准工序模板**：
```
拆除/改造 → 中央空调/新风 → 水电改造 → 防水 → 泥瓦（贴砖）→ 木工（吊顶/柜体）
→ 油漆（墙面）→ 安装（橱柜/门/开关/灯具）→ 开荒保洁 → 软装进场 → 入住
```

**主动引导能力**：
- 当前处于「水电改造」→ 自动提示"该预约中央空调安装了"
- 即将进入「泥瓦」→ 推送"瓷砖选购指南"+"本地建材市场推荐"
- 前置条件校验：水电未验收 → 不能进入泥瓦阶段（红色警告）
- 工序依赖可视化：用流程图展示当前进度和前后依赖

**每日待办清单**：
- 根据当前工序自动生成今日该做的事
- 可勾选完成，关联施工日记

### 3. 智能方案生成
> 上传户型图，AI帮你出主意

**户型图分析**：
- 上传户型图（拍照/相册/网络搜图）
- AI识别房间划分、承重墙、门窗位置
- 自动创建空间列表（无需手动添加房间）

**布局建议**：
- "3.6m宽的客厅，沙发和电视距离多少合适？"
- "厨房只有4平米，L型还是U型橱柜？"
- "主卧门对着卫生间门，怎么化解？"

**风格匹配**：
- 选择你喜欢的风格参考图 → AI推荐配色方案、地面材质、家具风格

### 4. 材料百科 + 家电选购指南
> 内置装修知识库，随用随查

**材料词典**：
- 瓷砖：通体/釉面/抛光/仿古 → 适用场景、价位、选购要点
- 地板：实木/多层/强化/SPC → 优缺点对比
- 涂料：乳胶漆/艺术漆/硅藻泥 → 环保标准、施工要求
- 五金/灯具/卫浴/门窗...（20+品类）

**家电清单**（按空间）：
- 厨房：烟机灶具、洗碗机、净水器、垃圾处理器、冰箱
- 卫生间：热水器、浴霸、智能马桶、电热毛巾架
- 客厅：电视/投影、空调、扫地机器人基站位置预留
- 阳台：洗衣机、烘干机、壁挂洗衣机

每条包含：推荐品牌、参考价位、安装前置条件（如"洗碗机需预留16A插座+进水+排水"）

## 技术方案补充（AI能力层）

| 能力 | 实现方式 | 说明 |
|------|---------|------|
| 文字问答 | 云函数 → LLM API（DeepSeek/通义千问） | 带装修知识库的 RAG 增强 |
| 拍照识别 | 云函数 → 多模态视觉模型 API | 图片理解+装修领域知识注入 |
| 户型图分析 | 云函数 → 视觉模型 + 结构化输出 | 识别房间/墙/门窗 |
| 流程引擎 | 本地状态机 + 云数据库工序模板 | 根据当前工序推送待办和提醒 |
| 知识库 | 云数据库存储结构化知识卡片 | 材料百科、家电清单、避坑指南 |
| 语音输入 | 微信原生`wx.joinVoIPChat` 或语音识别 | 方便工地上手脏时提问 |
